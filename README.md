# Media Shelf

A Java Swing desktop app for keeping track of the books, movies, and games I'm reading, watching, and playing.

Intermediate Java Programming project, Fall 2026. Aero Larson.

## Status

- Week 2: model classes (MediaItem, Book, Movie, Game, Library) are written with validation. `ModelTester` has some quick console tests.
- Week 3: ratings stats (2D array) and save/load to a text file. Sample files are in `data/`.
- Coming next: more testing, then the GUI.

## Running the tests

Open the project in Eclipse and run `mediashelf.ModelTester` as a Java Application.
